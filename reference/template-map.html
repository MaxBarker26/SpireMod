Working vocabulary

Model
Content definition and behavior, such as a potion or card. Godot nodes handle its visual/input side. BaseLib model guide.
Custom model
A BaseLib extension of a game model, with conveniences for modded content. Source.
Hook
A lifecycle method where content can respond to game activity. Model workflow.
Command
A game operation called by behavior; the guide recommends commands over direct data edits. Source.
Manifest / DLL / PCK
Metadata / compiled code / packaged resources. Mod file guide.
Patch
A runtime change to an existing method through Harmony. Harmony introduction.

The missing potion branch

A future concrete potion will inherit BaseLib.Abstracts.CustomPotionModel, directly or through a small project-specific base. This template has no such branch yet. Read the framework class for its image and localization extension points.

With the current project settings, dotnet build compiles and copies the DLL, manifest, and debug symbols. The optional quick PCK packer is commented out. Resource export is a separate publish/Godot path: a successful build alone does not prove the PCK is current.

Build observations come from this workspace's project file. Packaging background: Godot export documentation.
